Getting started

1. Keep the Discord desktop client (or Vesktop + arRPC) signed in on the Orca host, or enable the companion bridge.

2. Approve plugin consent (workspace, events, settings, notifications).

3. Open this right-sidebar tab: plugin:chron0.discord-presence/presence

4. Run Discord Presence: Show Status from the command palette.

Troubleshooting

Vesktop Flatpak: enable Rich Presence via arRPC. IPC lives under .flatpak/dev.vencord.Vesktop/xdg-run.

Reload RPC: command palette only — panels cannot invoke commands or reconnect the worker socket.

Competing RPC: another IDE or overlay can overwrite activity. Reload RPC or wait for the 90s heartbeat.

Logs: ~/.local/state/chron0-discord-presence/plugin.log (Windows: %LOCALAPPDATA%\chron0-discord-presence\plugin.log)

Toggles do not persist from this panel until the host flips settings.* to panel-callable. Tracked in issue #10.
